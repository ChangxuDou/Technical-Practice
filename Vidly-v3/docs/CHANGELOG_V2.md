# v2 变更

- 删除所有顾客自助归还、遗失和结算权限；服务层、视图及模板同时限制。
- 新增 MovieWish / WishRequest：片名标准化 + 年份去重，按独立顾客汇总。
- 新增 PurchaseOrder / StockReceipt：经理建采购单，店长或收银员分批收货，自动加库存上架，回写心愿进度。
- 新增 TopUp：本地模拟支付订单，30 分钟有效，金额/规则快照、终态不可重复入账。
- 新增 RewardPolicy / PolicyRevision：经理和超管共用配置，金额积分比例及充值开关，保存审计记录。
- 新增 PointsEntry：充值赠分、退款扣回；停止在租借结算时重复赠分。
- 余额退款按充值赠分的历史比例累计扣回，兼容部分退款。
- 初始化新增 --only-empty，重复启动不再恢复已删除电影。
- 新增数据库迁移 rentals.0002，支持上一版数据库升级；不修改原 ZIP 或上一版代码目录。
